02 · Núcleo Técnico de Ingeniería Agéntica
✻ ayesa digital

Plataforma como Producto: SDD + Prompt + Context + Harness & Loop Engineering

1. Spec-Driven Dev (SDD)
  • La especificación (specs/sdd-segurcaixa-servicios-clientes.md) es la fuente única de verdad.
  • Tríada de Agentes: Planificador, Implementador y Revisor QA.
  • Trazabilidad 1:1 Épica → Historia → Gherkin → Test (@pytest.mark.xray).
2. Prompt Engineering
  • Directivas estructuradas bajo el patrón R-C-I-O-V (Role, Context, Invariants, Output, Verification).
  • Prompts especializados para Page Objects resilientes, auto-curación DOM y diagnóstico SRE de JMeter.
3. Context Engineering
  • Protocolo MCP + RAG + Memoria compartida en el Hub ALM.
  • DOM Pruning (-92% tokens): selenium_inspect_dom_locators filtra solo nodos interactivos.
  • Carga jerárquica en 4 capas sin releer todo el repositorio.
4. Harness & Loop Eng.
  • Reglas normativas en AGENTS.md y AGENT.md.
  • Arnés determinista (run_qaops_suite.py) que valida todo el sistema en < 10 segundos.
  • Cada error detectado se convierte en una regla automatizada.
